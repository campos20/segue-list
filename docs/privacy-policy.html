Política de Privacidade do Segue List

Última atualização: 1 de setembro de 2026 · Read this in English

O Segue List é um aplicativo para músicos organizarem letras de música e setlists. Esta política explica, de forma direta, como o app trata dados, porque a resposta curta é: ele não coleta, não transmite e não compartilha dados pessoais com ninguém, incluindo o desenvolvedor.

Quais dados o app usa

As músicas, letras e setlists que você cria ficam salvas apenas como arquivos locais no armazenamento do seu próprio aparelho, usando os recursos de sistema de arquivos do Expo. Esses dados nunca saem do aparelho, exceto quando você mesmo decide exportá-los ou compartilhá-los (por exemplo, gerando um arquivo de backup ou enviando um setlist para outro músico) — nesse caso, é você quem escolhe o destino através do menu de compartilhamento nativo do seu sistema operacional (iOS/Android).

O que o app não faz

  • Não existe conta, login ou cadastro de usuário.
  • Não existe servidor ou backend próprio: o app funciona 100% offline.
  • Não há bibliotecas de analytics, rastreamento de uso, publicidade ou relatório de falhas (crash reporting) de terceiros.
  • Nenhum dado é vendido, alugado ou compartilhado com terceiros.
  • O app não acessa contatos, localização, câmera, microfone ou identificadores de publicidade.

Permissões do dispositivo

O app pode solicitar acesso a arquivos apenas para as ações que você iniciar explicitamente: importar uma letra de um arquivo (.txt, .docx, .odt, .pdf) usando o seletor de documentos do sistema, ou exportar/ compartilhar um backup do seu acervo. Nenhum desses acessos acontece em segundo plano.

Exclusão de dados

Como tudo fica salvo apenas no seu aparelho, excluir uma música, um setlist ou desinstalar o app remove esses dados permanentemente — não há cópia em nenhum servidor para ser apagada.

Crianças

O Segue List não é feito exclusivamente para crianças, mas seu conteúdo é neutro (organização de letras de música) e pode ser usado por qualquer pessoa que saiba ler, incluindo crianças. Como o app não coleta, não armazena em servidor e não transmite nenhum dado pessoal de nenhum usuário — adulto ou criança —, não há coleta, uso ou compartilhamento de dados de menores de idade em nenhuma circunstância.

Alterações nesta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização revisada no topo.
